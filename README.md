🏰 Return Home
Return Home is a text-based adventure game in JavaScript. Your goal: survive the forest and castle to get back home.

🎮 How to Play
Start in the Main Room — solve a JavaScript riddle to get food/water.

Scene 1: Forest — meet a wolf, bear, find food/water, reach the castle.

Scene 2: Castle — explore:

Corridor: puzzle, monster, pink object.

Kitchen: one box helps, one harms.

Stairs: go to cellar (needs key or strength) or 1st floor (unicorn, phone).

Fight or run from monsters.

Every action costs health, increases hunger/thirst.

⚙️ Features
Check player status anytime.

Eat/drink from inventory.

Use alert() for messages, prompt() for choices.

JS file: castle.js

Good luck!
